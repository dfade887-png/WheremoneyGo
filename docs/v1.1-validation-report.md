## Experimental bank capture boundary

- Android-only, disabled by default, opt-in setup UI.
- Strict package allowlist is empty until an anonymized real sample and verified package name are supplied.
- Reference fixture adapter uses `com.example.reference.bank`; this is not a claim of real-bank support.
- Tag `bank-notification-experimental-v0.1.0` validates only the Android scaffold, fixture adapter, repository lifecycle, privacy boundaries, and APK compilation. It does not indicate support for any real bank.
- Raw notification content is neither persisted nor logged by the implemented adapter/repository path.
- Pending confirmation, deduplication, ignore, and atomic expense confirmation are repository-tested.
- Native end-to-end receipt, follow-up notification actions, reboot behavior, and Statement-screen matching are not yet validated on a physical Android device.

## Known limitations

- Real bank adapter is blocked pending an anonymized notification sample and actual package identifier.
- Native Android instrumentation tests have not been added; current native verification is APK compilation plus Dart adapter/repository tests.
- Statement Production UI is not fully repository-bound.
- Windows desktop toolchain is not installed and is outside the Android scope.
