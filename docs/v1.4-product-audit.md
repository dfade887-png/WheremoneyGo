## Static/demo findings

- Accounts onboarding displays `เงินจริงรวม (Demo)` and adds a hardcoded 1,200 baht.
- Recurring onboarding renders four constant rows with no persistence.
- Saving account dropdown contains only `เชื่อมภายหลัง`.
- Multiple Dropdown widgets remain inside dialogs.
- Some add buttons have empty callbacks.

## Lifecycle finding

The application swaps the complete root screen from a `ListenableBuilder`. Mutating root state while a dialog, sheet, focus scope, or descendant route is mounted can detach the route ancestry before Flutter finishes dependency cleanup. Navigation must be coordinated outside transient routes; complex editors must use full routes and commit only after validation.
